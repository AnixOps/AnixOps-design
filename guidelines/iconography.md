# Iconography

- **Library: [Lucide](https://lucide.dev)** (ISC license). SF Symbols are
  not allowed outside Apple-platform apps, so never use them.
- **Stroke 1.5 px**, round caps and joins, `currentColor`.
- **Sizes**: 20 px in navigation, 16 px inside buttons and table cells,
  48 px for empty-state illustrations.
- An icon-only button always has an `aria-label` and a tooltip.
- Never replace an icon with text ("DB", "☰", "x"). Dialog close buttons use
  the Lucide `x` icon or the `×` character.
- Icons inherit `--label-2` at rest and `--accent` when selected.
- Custom icons follow the Lucide grid: 24 × 24, 2 px padding, 1.5 px stroke.
- The AnixOps mark is not an icon: do not use it as a navigation glyph.
